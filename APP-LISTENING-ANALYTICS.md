# Nfinite Creators 0.57.1: App Listening Analytics

Adds app-specific qualified-audio surfaces (`app_music`, `app_radio`, `app_release`, `app_creator`) and explicit skip/end-reason storage to the existing Nfinite Engagement pipeline. Creator Analytics can therefore separate website and app listening without introducing a second earnings ledger.

Install this core update before PairOfDice Player 0.3.0. Existing engagement rows are preserved; the engagement table migrates in place.
